# AI 桌宠机器人融资官网

一套无需构建工具、可直接部署到 GitHub Pages 的静态官网。

## 上线前需要替换

1. 将页面中的品牌名 `AI DESKPET` 替换为正式公司或产品名称。
2. 将 `contact@yourcompany.com` 替换为正式商务邮箱。
3. 如有正式融资数据、团队信息与里程碑，可在现有版式上继续补充。

## GitHub Pages 部署

将本目录全部文件上传到 GitHub 仓库，在仓库的 `Settings → Pages` 中选择：

- Source：`Deploy from a branch`
- Branch：`main`
- Folder：`/ (root)`

保存后即可获得免费公开网址。
